California House Price Prediction

A Machine Learning web application built using Python, Flask, NumPy, and Scikit-learn to predict median house values in California based on various housing and geographical features.

🚀 Project Overview

This project uses a trained Machine Learning model to estimate California house values based on user-provided inputs through an interactive web interface.

Users can enter housing details and get instant predictions.

✨ Features

Predict California median house values.

Interactive and user-friendly web interface.

Real-time predictions using a trained ML model.

Input validation and error handling.

Flask backend integration.

Pre-trained model loaded using Joblib.
